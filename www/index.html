Offline-Modus
Offline-Moduswird geprüft …

Die App kann nicht erkennen, ob das Zertifikat installiert ist oder ob du in Safari einmal „Diesen Server vertrauen“ getippt hast. Eine solche Ausnahme kann verloren gehen, zum Beispiel beim Löschen der Website-Daten. Dauerhaft sicher ist nur das installierte Zertifikat (Einstellungen → Allgemein → Info → Zertifikatsvertrauenseinstellungen).

ioBroker-Zertifikat dauerhaft installieren

Damit die App sicher offline starten kann, muss dein iPhone dem Zertifikat deines Servers vertrauen:

  1. „ioBroker-Zertifikat laden“ tippen und „Zulassen“ wählen.
  2. Einstellungen → Allgemein → VPN & Geräteverwaltung → heruntergeladenes Profil → Installieren.
  3. Einstellungen → Allgemein → Info → Zertifikatsvertrauenseinstellungen → Zertifikat aktivieren.
  4. App schließen und neu öffnen.

„Erneut prüfen“ löscht den Offline-Speicher und meldet ihn neu an. Das klappt nur, wenn dein iPhone dem Zertifikat wirklich vertraut.

ioBroker-Zertifikat laden

Der Server stellt kein Zertifikat zum Laden bereit (in den Adapter-Einstellungen HTTPS aktivieren und ein Zertifikat wählen).
